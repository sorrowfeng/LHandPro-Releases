# LHandPro Releases Mirror

This repository is a release-only mirror for `sorrowfeng/LHandPro`.

- It intentionally contains no private source code.
- The source repository triggers the sync workflow after a Release is published.
- The mirror does not poll the private source repository on a schedule.
- Each dispatch carries one Release tag; **every asset** of that Release is mirrored (Windows zip, Linux `.deb` / `.tar.gz`, macOS `.dmg`, `SHA256SUMS`, ...).
- The two `Source code (zip/tar.gz)` entries on the GitHub release page are generated by GitHub and are not Release assets, so they are not mirrored; manually uploaded `src-*.zip` archives and half-uploaded assets are skipped as well.
- Drafts and non-canonical tags are rejected.
- End users should download packages from the GitHub Releases page.
